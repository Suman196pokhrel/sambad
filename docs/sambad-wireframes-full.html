The distinction this screen has to get right. A question can go unanswered because the content genuinely doesn't exist, or because retrieval failed to find content that does. Only the first is a knowledge gap. Mislabelling the second sends admins off to write documents they already have — so "Not a gap" needs to feed back into your retrieval evaluation, not just disappear.
